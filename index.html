Final Project: Personal Portfolio Website (HTML/CSS) Creative Edition

📌 Assignment Overview

For you final project in this course, you will design a personal portfolio website using only HTML and CSS. this website will showcase who you are, what you've learned, and how you can apply creativity through code. the main pocus of this project is to explore your own visual style and demonstrate your understanding of frontend design principles.



🎯 Project Objectives

By the end of this assignment, you should be able to:

  • Build a multi-page or single-page website using clean, semantic HTML.

  • Apply CSS to create engaging and responsive layouts.

  • Demonstrate creativity through design choices (color schemes, typography, layout).

  • Showcase your personal brand or interests.


📂 Required Pages

You must include at least 3 pages or sections if (single-page):

  1. Home - Introduction and welcome message.

  2. About me - A creative biography or story of yourself.

  3. Portfolio / Projects - Showcase your class projects, hobbies, or even imaginary work.

Optional bonus pages
